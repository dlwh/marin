# Grug MoE 235B v5p-256: Research Logbook

## Scope
- Goal: Launch and monitor a short Grug MoE trial near the Qwen3-235B-A22B geometry on `v5p-256`, with `topk=4` and a shared expert width set to `2x` the routed expert width.
- Primary metric(s): successful start, progress through step `18`, profile artifact for steps `9-11`, and any HBM/host-memory or Iris orchestration failures.
- Constraints: use Iris in `us-central1-a`; do not mutate the cluster outside the monitoring-loop guardrails; keep the run broadly aligned with [#3096](https://github.com/marin-community/marin/issues/3096).
- Experiment issue: [#3536](https://github.com/marin-community/marin/issues/3536)

## Baseline
- Date: 2026-03-11
- Code refs: `codex/grug-moe-v5p64-perf`, [#3096](https://github.com/marin-community/marin/issues/3096), [#3357](https://github.com/marin-community/marin/issues/3357)
- Baseline numbers:
  - Prior profiled Grug MoE bring-up used a Qwen3-like `~32B total / ~4B active` shape on `v5p-64`.
  - Best prior cheap-architecture signal: `topk=4` was a real efficiency win on the `32B` family, and wider shared experts were viable.
